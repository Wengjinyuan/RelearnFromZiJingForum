# F01-F11 从 0 做方案：学习索引

这组文档不再只回答“代码怎么走”，而是模拟你第一次设计论坛功能时的思考过程：为什么需要它、先会遇到什么问题、为什么选当前技术、为什么不选同类方案，以及技术债是否已经解决。

## 建议阅读方法

每个功能按下面的顺序学习：

1. 先读 `DesignFromZeroFXX.md`，训练需求分析和技术选型。
2. 再读 `NeedToUnderstandingFXX.md`，把方案映射到类、方法、SQL 和事务。
3. 最后读 `GUIDE.md`，按练习和验收入口自己复现。
4. 合上答案，用文末的面试追问口述一遍；重点说清楚边界和缺陷，不要把“可选依赖”说成“线上已启用”。

## 面试回答模板

回答每个功能时，用这条主线：

> 业务问题是什么 → 最小可用方案是什么 → 当前代码选了什么技术 → 它具体负责哪一步 → 为什么没有选另一种方案 → 它引入了什么新问题 → 当前是解决、缓解、可接受还是待办 → 如果规模上升下一步怎样演进。

这个模板比只背“项目用了 Redis、RabbitMQ、Elasticsearch”更可靠，因为面试官继续追问时，你能说清每项技术出现的条件和代价。
