# 前端联调与本地图片

## 先跑起来

在 IDEA 运行 `RebuiltZijingForumApplication`，或在项目根目录执行 `mvn spring-boot:run '-Dspring-boot.run.arguments=--server.port=18080'`。访问 `http://localhost:18080/index.html`。默认数据源是 `application.yml` 配置的文件型 H2；`data/` 中已有数据不会因重启清空。首次演示账号为 `demo_admin`、`demo_alice`、`demo_bob`，密码均为 `Demo12345`。自己注册的账号保留注册时的密码，也可用账号、邮箱或手机号登录。

## 功能从页面走到数据库

| 页面动作 | Controller | Service / 数据库 |
| --- | --- | --- |
| 登录页申请重置 | `PasswordResetRequestController.request` | `PasswordResetRequestService.request` 查询 `user_account`，插入 `password_reset_request`；不存在的账号返回同样的提交提示 |
| 管理员批准 | `PasswordResetRequestController.approve` | Service 校验 `ADMIN`，将 BCrypt 密码改为 `123456`，递增 `token_version`，写 `admin_audit_log` |
| 管理员改权限 | `AdminUserController.changeRole` | `AdminUserServiceImpl.changeRole` 校验角色和目标，`AdminMapper.setUserRole` 更新 `user_account`，旧令牌失效 |
| 编辑邮箱、手机号 | `ContactController.update` | `ContactService.update` 只更新本人 `user_account`；邮箱/手机号唯一约束阻止重复 |
| 编辑昵称、生日等 | `ProfileController.updateOwnProfile` | `ProfileServiceImpl` 更新 `user_profile` |
| 本地头像 | `ProfileController.uploadOwnAvatar` | 校验图片后保存到 `uploads/avatars/{用户ID}/`，数据库 `user_profile.avatar_url` 保存站内 URL |
| 帖子或评论图片 | `PostImageController.upload` | 校验图片后保存到 `uploads/posts/`，编辑器或评论把 `/uploads/posts/...` 写入内容 |
| 点赞、收藏与刷新 | `InteractionController` | `InteractionServiceImpl` 写 `like_record`/`favorite`；前端刷新后调用 `/api/interactions/posts/{id}/state` 读真实状态 |
| 右上角统计 | `ProfileStatsController.stats` | 查询 `follow_relation` 和已发布 `post`，鼠标移入头像时重新读取 |

权限的第一道检查在 `AuthenticationInterceptor.preHandle`，管理员角色在 Service 再检查一次。图片目录 `uploads/` 已被 Git 忽略，后续接阿里云时可以替换存储实现与返回 URL；目前不需要 HTTPS 图片地址，本地文件选择框会先上传文件，再使用本站的 `/uploads/...` 地址。切换到已有 MySQL 库时使用 `migration-mysql-20261012.sql` 补生日列和重置申请表。
